## Platform

web

## Stack

Static HTML/CSS/JS (user's explicit choice — no framework, no build step). The hero's choreography is hand-rolled CSS + vanilla JS. One library, vendored: **Motion** (motion.dev, `js/vendor/motion.js`, UMD global `window.Motion`) — the vanilla-JS engine behind Framer Motion, added at the user's request for the Work slider's springs and staggers. Vendored rather than CDN-linked so the site still opens straight off disk with no build step; everything that uses it degrades if it fails to load.

## Users

Recruiters, hiring managers, design leads, and potential freelance clients evaluating Ilia Okhanashvili as a mid-level UI/UX designer. They arrive from a CV link, LinkedIn/Behance, or a job application, usually skimming quickly on desktop or mobile.

## Product Purpose

Personal portfolio site for Ilia Okhanashvili, mid-level UI/UX designer. Success = a visitor immediately understands who Ilia is, feels the craft quality from the site itself (the site is a work sample), and moves toward viewing work or making contact.
